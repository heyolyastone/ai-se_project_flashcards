# Flashcard App

My first project in TripleTen's AI-Assisted Software Engineering program. It includes decks of flashcards, each of which can be viewed in a carousel.

## Features

- View flashcard decks
- Open a carousel for each deck
- Flip cards to see the answer
- Navigate between cards
- Responsive layout based on the project design

## Technologies used

- HTML
- CSS
- JavaScript
- Git and GitHub
- BEM methodology
